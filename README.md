# מטלה שנייה - מחלקות, בנאים ומפרקים

## יושרה אקדמית

במהלך העבודה על המטלות, מותר להתייעץ עם סטודנטים אחרים ולחפש מידע באינטרנט. עם זאת, חל איסור להעתיק קטעי קוד שלמים ממקורות חיצוניים, כולל סטודנטים אחרים, אתרי אינטרנט ומודלי בינה מלאכותית (כגון ChatGPT).

יש לדווח על כל עזרה שקיבלתם, בין אם מדובר בהתייעצות עם סטודנטים אחרים או במידע שנמצא באינטרנט, בהתאם ל[תקנון היושר של המחלקה](https://www.ariel.ac.il/wp/cs/wp-content/uploads/sites/88/2020/08/Guidelines-for-Academic-Integrity.pdf).
**במקרה של שימוש בכלי בינה מלאכותית (AI), יש לצרף את הפרומפטים שהוזנו ואת התשובות שהתקבלו**.


## הקדמה
מטלה זו היא חלק מהקורס "C++ תכנות מתקדם" ומטרתה להדגים את היתרונות והתכונות המיוחדות של שפת C++ בהשוואה לשפות תכנות אחרות כגון C ו-Java. המטלה מתמקדת ביישום מערכת ניהול ספריית מוזיקה הכוללת שירים, פלייליסטים וספרייה מרכזית, ומדגישה את הפיצ'רים הייחודיים של C++ כגון ניהול זיכרון דינמי, בנאים ומפרקים.

## מבנה המטלה
במטלה זו תתבקשו להשלים קוד חסר במספר קבצים שמממשים מחלקות ופונקציות שונות. הקבצים מתארים מחלקות לניהול מוזיקה (`Song`, `Playlist`, `MusicLibrary`) הכוללות בנאים, מפרקים, ניהול זיכרון דינמי ואיברים סטטיים.

## דרישות והנחיות
- להשלים את הקוד החסר בקבצים שסופקו
- לוודא שהקוד מתקמפל ופועל ללא שגיאות
- להדגים את היכולות והיתרונות הייחודיים של שפת C++
- להקפיד על כתיבה תקנית ותיעוד מתאים
- לעבור בהצלחה את הטסטים הכתובים בקובץ test.cpp

## תכונות C++ שיש להדגים
1. **מרחבי שמות (Namespaces)** - שימוש במרחב השמות `music` להפרדת קוד
2. **מחלקות (Classes)** - ייצוג `Song`, `Playlist` ו-`MusicLibrary` עם encapsulation מלא
3. **בנאים ומפרק (Constructors & Destructor)** - ברירת מחדל, עם פרמטרים, בנאי העתקה ומפרק
4. **ניהול זיכרון דינמי (Dynamic Memory)** - שימוש ב-`new`/`delete` ומערכים דינמיים
5. **הפרדה בין הצהרה למימוש** - שימוש נכון בקבצי `.hpp` ו-`.cpp`
6. **איברים סטטיים (Static Members)** - מעקב אחר מספר אובייקטים ונתונים כלל-מחלקתיים
7. **טיפוסי נתונים (Data Types)** - שימוש ב-`std::string`, `int`, `bool`
8. **קלט/פלט זרמים (Streams)** - שימוש ב-`iostream` לפלט (`cout`)
9. **בדיקות יחידה (Unit Testing)** - שימוש בספריית doctest לבדיקות

## קבצים במטלה

### קבצים שסופקו:
- **MusicLibrary.hpp** - קובץ הכרזה של מחלקת `MusicLibrary` המנהלת אוסף של פלייליסטים באמצעות מערך דינמי; כולל בנאים, מפרק, איבר סטטי לסטטיסטיקות ומתודות לניהול פלייליסטים
- **Song.hpp** - קובץ הכרזה של מחלקת `Song` המייצגת שיר עם שם, אמן ומשך זמן; כולל בנאים, מפרק, מימושים inline לגטרים ואיבר סטטי לספירת אובייקטים
- **Playlist.hpp** - קובץ הכרזה של מחלקת `Playlist` המנהלת מערך דינמי של מצביעים לשירים; כולל העתקה עמוקה (deep copy), שינוי גודל אוטומטי, ומתודות להוספה, הסרה וחיפוש שירים
- **main.cpp** - תוכנית ראשית המדגימה שימוש בכל הפונקציות עם הערות המציינות את הפלט הצפוי
- **test.cpp** - קובץ בדיקות יחידה מקיף הבודק את כל המחלקות (`Song`, `Playlist`, `MusicLibrary`) כולל מקרי קצה וחריגות
- **doctest.h** - ספרייה לביצוע בדיקות אוטומטיות
- **Makefile** - קובץ לקימפול והרצה אוטומטית של הפרויקט

### קבצים שעליכם ליצור ולממש:
- **MusicLibrary.cpp** - מימוש מתודות מחלקת `MusicLibrary`: בנאים, מפרק, `resize`, הוספת פלייליסטים, חיפוש ושליפת נתונים סטטיסטיים
- **Song.cpp** - מימוש מתודות מחלקת `Song`: בנאים (כולל וולידציה על משך הזמן), מפרק, סטרים, `getFormattedDuration` וניהול האיבר הסטטי `songCount`
- **Playlist.cpp** - מימוש מתודות מחלקת `Playlist`: בנאים (כולל העתקה עמוקה), מפרק עם שחרור זיכרון מלא, `resize`, `addSong`, `removeSong`, `findSong` ו-`getFormattedTotalDuration`

## הוראות קימפול והרצה

### שימוש ב-Makefile:
הפרויקט כולל `Makefile` שמאפשר קימפול והרצה בקלות:

```bash
make              # מקמפל ומריץ את התוכנית הראשית
make test         # מקמפל ומריץ את בדיקות היחידה
make student_test # מקמפל ומריץ את בדיקות הסטודנט
make tidy         # מריץ clang-tidy לבדיקת איכות הקוד
make clean        # מנקה את כל קבצי הקימפול
```

## בדיקות מותאמות אישית (StudentTest.cpp)

עליכם ליצור קובץ בשם `StudentTest.cpp` המכיל לפחות **20 מקרי בדיקה** (test cases) ייחודיים משלכם תוך שימוש ב-doctest.

דרישות:
- הקובץ חייב להכיל `#define DOCTEST_CONFIG_IMPLEMENT_WITH_MAIN` ו-`#include "doctest.h"`
- יש לכתוב לפחות 20 מקרי בדיקה שונים מהמופיעים ב-`test.cpp`
- הבדיקות חייבות לבדוק את המחלקות `Song`, `Playlist` ו-`MusicLibrary`
- הרצה: `make student_test`
