# מטלה שנייה - מחלקות, בנאים ומפרקים

## יושרה אקדמית

במהלך העבודה על המטלות, מותר להתייעץ עם סטודנטים אחרים ולחפש מידע באינטרנט. עם זאת, חל איסור להעתיק קטעי קוד שלמים ממקורות חיצוניים, כולל סטודנטים אחרים, אתרי אינטרנט ומודלי בינה מלאכותית (כגון ChatGPT).

יש לדווח על כל עזרה שקיבלתם, בין אם מדובר בהתייעצות עם סטודנטים אחרים או במידע שנמצא באינטרנט, בהתאם ל[תקנון היושר של המחלקה](https://www.ariel.ac.il/wp/cs/wp-content/uploads/sites/88/2020/08/Guidelines-for-Academic-Integrity.pdf).
**במקרה של שימוש בכלי בינה מלאכותית (AI), יש לצרף את הפרומפטים שהוזנו ואת התשובות שהתקבלו**.


## הקדמה
מטלה זו היא חלק מהקורס "C++ תכנות מתקדם" ומטרתה להדגים את היתרונות והתכונות המיוחדות של שפת C++ בהשוואה לשפות תכנות אחרות כגון C ו-Java. המטלה מתמקדת ביישום מערכת ניהול ספריית מוזיקה הכוללת מחלקות לייצוג שירים, רשימות השמעה וספרייה מוזיקלית, תוך הדגשת הפיצ'רים הייחודיים של C++.

## מבנה המטלה
במטלה זו תתבקשו להשלים קוד חסר במספר קבצים שמממשים מחלקות ופונקציות שונות. הקבצים מתארים מחלקות לניהול ספריית מוזיקה (`Song`, `Playlist`, `MusicLibrary`) במרחב השמות `music`.

## דרישות והנחיות
- להשלים את הקוד החסר בקבצים שסופקו
- לוודא שהקוד מתקמפל ופועל ללא שגיאות
- להדגים את היכולות והיתרונות הייחודיים של שפת C++
- להקפיד על כתיבה תקנית ותיעוד מתאים
- לעבור בהצלחה את הטסטים הכתובים בקובץ test.cpp

## תכונות C++ שיש להדגים
1. **מרחבי שמות (Namespaces)** - שימוש במרחב השמות `music` להפרדת קוד
2. **מחלקות (Classes)** - שימוש במחלקות `Song`, `Playlist` ו-`MusicLibrary` עם בנאים, מפרקים ומשתנים סטטיים
3. **בנאים ומפרקים (Constructors/Destructors)** - בנאי ברירת מחדל, בנאי עם פרמטרים, בנאי העתקה ומפרק
4. **קלט/פלט זרמים (Streams)** - שימוש ב-`iostream` לפלט (`cout`)
5. **הפרדה בין הצהרה למימוש** - שימוש נכון בקבצי `.hpp` ו-`.cpp`, פונקציות inline מול outline
6. **הקצאת זיכרון דינמית** - שימוש ב-`new`/`delete` לניהול מערכים דינמיים של מצביעים
7. **טיפוסי נתונים (Data Types)** - שימוש ב-`string`, `int`, `bool`
8. **משתנים סטטיים (Static Members)** - מעקב אחרי מספר אובייקטים ופעולות
9. **בדיקות יחידה (Unit Testing)** - שימוש בספריית doctest לבדיקות

